 b) DCL COMMAND 
 Create two users user1, user2 
 1. GRANT:   Give insert and select privilege to user 1 on customer table in the invoice 
 mysql> CREATE USER 'nihadc'@'localhost' IDENTIFIED BY 'Nihad1@2004';
Query OK, 0 rows affected (0.10 sec)
 mysql> CREATE USER 'nihad2'@'localhost' IDENTIFIED BY 'Nihad2@2004';
Query OK, 0 rows affected (0.10 sec)

mysql> GRANT SELECT ON INVOICE.customer TO 'nihadc'@'localhost';
Query OK, 0 rows affected (0.09 sec)
mysql> GRANT SELECT ON INVOICE.customer TO 'nihad2'@'localhost';
Query OK, 0 rows affected (0.20 sec)
